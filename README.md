# SNHU_CS330
Comp Graphic and Visualization

1. How do I approach designing software?

   Working on this 3D camping scene helped me learn how separate shapes should/would fit together to create larger objects. I designed this scene by identifying its main elements (tent, trees, fire, ground/sky) - then choosing basic 3D shapes to build them. Creating the objects in the scene, I considered each position, scale, color, and texture to achieve a cohesive feel.
     This design process involved breaking the scene into smaller parts and adjusting them as the scene developed. I used transformations to position and resize shapes, then refined their appearance with textures and lighting. This approach helped me see how small design choices affect the entire scene. I can use the same process in future projects by outlining the result I want, separating it into manageable pieces, and refining each as I compile the scene.

2. How do I approach developing programs?
   I used a gradual, iterative approach to development. I added objects and features, ran the program, and checked whether each change produced the intended result. When something looked wrong or disappeared, I adjusted values and tried again.
     Over the course of this project, my overall approach became systematic. Instead of changing multiple values at once, I began isolating the parts I believed to be causing the issue, then testing smaller changes or adding print values that would display in the console and show me where things weren't working properly. This made it easier to complete the scene and will help me develop and troubleshoot future programs.

3. How can computer science help mee in reaching my goals?
   Computational graphics and visualization taught me how computers represent and display objects using coordinates, transformations, textures, lighting, and cameras. These skills can support my future education by giving me a stronger understanding of programming concepts and how software turns data into a visual result.
     As an Information Security student, this knowledge can also be applied professionally. Visualizations can help explain complex systems, show how network components relate, or make security data easier to interpret. Learning to build and debug a graphic program also strengthened my problem solving skills, which will be useful in security or other technical roles.
